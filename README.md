# OpenCrate

### A local-first music downloader and library builder

Turn song links and playlists into organized audio files with cover art and editable music tags. OpenCrate runs on your computer, keeps your library in local folders, and uses open-source tools for media processing.

[Get started](#quick-start) · [What it does](#features) · [Setup](#requirements) · [FAQ](#faq)

</div>

OpenCrate is a free, open-source, self-hosted music library downloader for people who want portable audio files and control over their music collection. Paste a single song link or import a playlist or album, find a source when needed, choose an audio format, and save tagged tracks with artwork to your computer.

It supports Spotify track, album, and playlist metadata; YouTube and YouTube Music videos, playlists, albums, and Mix links; and direct song URLs handled by [yt-dlp](https://github.com/yt-dlp/yt-dlp), including supported SoundCloud and Bandcamp links. Spotify links provide metadata and matching; OpenCrate does not extract Spotify audio. Download only audio you have permission to save.

## Features

- **Paste one song link or a collection.** Add a single track from a supported direct source, or import a Spotify / YouTube playlist or album.
- **YouTube Mix links.** Mix URLs that include both `v=` and `list=RD...` retain the seed video needed to read the mix.
- **Automatic source matching.** Find YouTube or SoundCloud candidates for tracks without a direct source. Review and change matches before downloading.
- **Tagged audio files.** Save MP3, FLAC, M4A, or Opus with title, artist, album, album artist, date, track number, disc number, and embedded cover art where available.
- **Organized local folders.** Build albums, playlists, and singles with artwork folders, an M3U playlist, a JSON manifest, and an optional ZIP archive.
- **Editable metadata.** Correct track tags, source URLs, and cover art in the browser. Update tags on existing audio without downloading it again.
- **Private by default.** The web interface binds to `127.0.0.1`; jobs and files stay on your machine. No account, cloud conversion service, subscription, or bundled Spotify credentials.
- **Portable collections.** Import or export playlist JSON and move the project data folder between computers.

## Quick start

### Requirements

- Node.js 22 or later
- Python 3
- FFmpeg
- yt-dlp
- Mutagen (`python3 -m pip install mutagen`)

### Install and run

```sh
git clone https://github.com/Buku313/OpenCrate.git
cd OpenCrate
python3 -m venv .venv
.venv/bin/python -m pip install 'yt-dlp[default]' mutagen
npm start
```

Open <http://127.0.0.1:4783>. On macOS, you can also double-click `OpenCrate.command` after installing the requirements. On Windows, use `.venv\Scripts\python.exe` for the pip command. OpenCrate has no npm dependencies or frontend build step.

To select specific binaries or a different data folder, set `YTDLP_BIN`, `PYTHON_BIN`, or `OPENCRATE_DATA`. Set `PORT` to use another local port. `SPOTIFY_ACCESS_TOKEN` is an optional user-provided token for private playlists you own or collaborate on.

## Import a song or playlist

Paste a single song URL to add one track. Supported direct URLs depend on yt-dlp's current extractors. Spotify track links import metadata and can be matched to a YouTube or SoundCloud source when you choose **Download selected**. YouTube videos and supported direct-source tracks arrive with their source URL ready.

Paste a Spotify playlist or album, or a YouTube / YouTube Music playlist or album, to add a collection. YouTube watch links with a playlist ID import that playlist. For a YouTube Mix, paste the complete link, including both `v=` and `list=RD...`; OpenCrate preserves the seed video when reading the Mix. Mix contents are generated by YouTube and may change between imports.

Use **Find matches** to inspect candidates before downloading. Matching ranks title, artist, and duration, but it can still choose the wrong recording. You can change the source URL or choose another candidate. Download only media you have permission to save; platform availability and extractor support can change.

### Spotify access

Public Spotify embeds need no login and may omit playlist entries. Check the imported track count. For complete private or collaborative playlists, add your own Spotify access token in Settings; it stays in the browser tab's memory and is sent to Spotify by the local backend. Spotify API permissions may be required. OpenCrate does not stream or extract Spotify audio and does not bypass DRM.

## Audio, artwork, and folders

MP3, FLAC, M4A, and Opus files receive portable tags and embedded front-cover art. MP3 uses ID3v2.3, M4A uses MP4 tags, FLAC uses a native picture block, and Opus uses `METADATA_BLOCK_PICTURE`. Tagging does not re-encode audio. FLAC or a higher bitrate cannot restore quality lost in a lossy source.

OpenCrate prefers original cover art where available, then source thumbnails and collection art. Missing album fields remain editable rather than being guessed. Downloads are grouped into `Albums/`, `Playlists/`, or `Singles/` under `data/downloads/`. Each collection can include per-track artwork, `cover.jpg`, `playlist.m3u8`, and `manifest.json`; completed collections can also be downloaded as ZIP files. Existing folders get a numbered suffix to avoid silent overwrites.

## FAQ

**Can I paste just one song link?** Yes. Paste a direct song URL from a supported extractor, a YouTube video URL, or a Spotify track URL. Direct media sources are ready to queue; Spotify tracks need a source match.

**Why did my YouTube Mix not import?** Mix links need the seed video (`v=...`) as well as the Mix playlist ID (`list=RD...`). Copy the full link from the Mix video or playlist. A Mix is generated by YouTube, and YouTube or yt-dlp availability can vary.

**Does OpenCrate download songs from Spotify?** No. Spotify links provide track and collection metadata. OpenCrate can find a separate source for a Spotify track, which you should review before downloading.

**Where are my files stored?** By default, in `data/downloads/` inside the project. Set `OPENCRATE_DATA` to choose another data directory.

**Does OpenCrate send my library to a cloud service?** No. The server listens only on your own computer. Source providers are contacted to read metadata, search for matches, or retrieve the source you select.

## Configuration

| Variable | Purpose |
| --- | --- |
| `OPENCRATE_DATA` | Directory for job state and downloaded files |
| `YTDLP_BIN` | yt-dlp executable path |
| `PYTHON_BIN` | Python executable with Mutagen installed |
| `PORT` | Local web server port (default `4783`) |
| `SPOTIFY_ACCESS_TOKEN` | Optional Spotify API token |
